# TRQX Video Walk-Through Guide

## Purpose

This guide turns each TRQX feature into a repeatable training video.

## Standard Video Format

1. Hook: 10 to 20 seconds
2. Explain the problem
3. Show where the tool is
4. Demonstrate the tool
5. Explain the result
6. Show one common mistake
7. Give the next action
8. Call to action
