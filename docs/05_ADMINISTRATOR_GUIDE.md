## Release Checklist

- Confirm current branch.
- Confirm production build passes.
- Review `git status`.
- Exclude secrets, backups, ZIP files, and temporary scripts.
- Test login.
- Test dashboard.
- Test paid-feature gating.
- Test Academy.
- Test Engineering Lab.
- Review deployment logs.
- Verify production routes.
- Create a release tag.
- Create a backup.
